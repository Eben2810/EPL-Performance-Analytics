# EPL-Performance-Analytics

## Project Overview

This project proposes an EPL Team Performance Decision-Support Dashboard. The purpose of the dashboard is to help club managers and front-office executives compare a team's actual performance with its expected performance. The dashboard would use measures such as points, expected points (xPTS), goals, expected goals (xG), goals against, and expected goals against (xGA). The goal is to present these measures in a simple and easy-to-understand format that can support team performance decisions.

## Decision-Making Problem

League position and points show how a team has performed, but they may not always provide a complete picture of the team's underlying performance. A team may earn more or fewer points than its performance statistics suggest. This analytics idea would help decision makers identify differences between actual and expected performance and determine areas that may need further investigation.

## Proposed Analytics Approach

The project would use historical EPL team-level data. The data would include wins, draws, losses, goals, goals against, points, expected goals (xG), expected goals against (xGA), and expected points (xPTS). Actual performance measures would be compared with expected performance measures to identify important differences and patterns. The results would then be presented through a simple dashboard.

## Use by Decision Makers

Club managers and front-office executives could use the dashboard to compare team performance across seasons and identify important performance gaps. For example, they could identify when a team earns considerably more or fewer points than expected. This information could support discussions about team strategy, player recruitment, coaching, and areas that may require additional analysis.

## Prototype Enhancement

The prototype adds a performance alert feature to the original EPL Team Performance Decision-Support Dashboard. Instead of requiring decision makers to review every performance measure, the dashboard would highlight important differences between actual and expected team performance.

For example, the dashboard could flag situations where a team's actual points are noticeably different from its expected points (xPTS), or where actual goals are considerably different from expected goals (xG). These alerts would help decision makers quickly identify unusual performance patterns that may require further investigation.

This change could improve decision-making because managers and front-office executives would be able to focus their attention on the most important performance differences. Instead of reviewing every number on the dashboard, they could quickly identify areas that may require additional analysis or action.
## Prototype Evaluation

The performance alert enhancement could improve the original dashboard because it would make important performance information easier for decision makers to identify. However, feedback should be collected from the people who would use the dashboard before the enhancement is fully integrated into the main project.

Managers and front-office executives could provide feedback about which differences between actual and expected performance are important enough to generate an alert. They could also provide feedback about how the alerts should be displayed and whether the feature makes the dashboard easier to understand and use.

Based on this evaluation, I believe the performance alert enhancement should be integrated into the main project because it could help decision makers identify important performance differences more quickly. However, feedback from users would still be important for improving the feature after integration.
